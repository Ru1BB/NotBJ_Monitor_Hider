# 京途 · 北京周边探头地图

首版移动端优先 Web 应用：高德地图、浏览器定位、手动选点、附近探头列表及来源详情。附近距离计算完全在浏览器内完成，服务端不接收或保存用户位置。

## 部署方式

这是一个带 Node.js 后端的 Web 应用：后端负责读取并缓存来源数据、提供接口和高德安全代理，前端是 `public/` 中的静态页面。适合有 Node.js 运行环境的服务器或支持长驻 Node.js 服务的平台；不能仅上传 `public/` 到纯静态网站托管。当前路径从域名根目录开始（`/api/`、`/app.js` 等），推荐使用独立域名或子域名，并将全部请求反向代理到 Node 服务；直接放在已有网站的子目录下需要另行修改路径和代理配置。

## 本机预览（Windows PowerShell）

需要 Node.js 20 或更高版本，无第三方 npm 依赖。在本目录打开 PowerShell：

```powershell
node server.js
```

打开 http://127.0.0.1:3000，在页面输入已配置 Key 对应的高德安全密钥，然后点击加载地图。密钥不保存在本地存储，刷新或关闭页面后需重新输入。手动输入模式使用高德的浏览器端明文配置，密钥会进入浏览器运行环境及高德请求，不适合保护共享的生产密钥；生产环境推荐使用下述服务端代理模式。探头数据要求服务器能访问进京365。关闭终端或按 Ctrl+C 停止服务。

必须通过环境变量 `AMAP_KEY` 配置自己的 JS API Key。`localhost` / `127.0.0.1` 可用于本机定位；手机通过局域网访问或正式部署时应使用 HTTPS。正式域名需符合高德 Key 的域名白名单。

## 其他环境运行

需要 Node.js 20 或更高版本，无第三方 npm 依赖。

```sh
AMAP_KEY='你的高德 Web 端 JS API Key' AMAP_SECURITY_CODE='你的安全密钥' npm start
```

浏览器访问 http://127.0.0.1:3000。生产部署需使用 HTTPS，设置 `HOST=0.0.0.0` 并在高德控制台配置域名白名单。`PORT` 可修改端口。Key 使用自己的高德账号申请；安全密钥仅保存在服务端环境变量，前端通过 `/_AMapService/` 代理访问高德安全服务。确认高德服务额度、费用与使用条款。未配置 Key 时页面会显示地图加载失败。

有请求到达且缓存超过 10 分钟时，服务端尝试更新来源数据，手动刷新最短间隔 1 分钟，并发请求合并；失败时保留进程内最近一次成功的数据。重启后缓存会丢失。解析失败或记录数相对上次减少超过一半不会覆盖缓存。数据字段作为不可信文本处理，详情链接仅允许进京365域名。

## 验证与上线前事项

```sh
npm test
```

- 根据 2026-11-11 的来源页面格式说明，解析器读取 `position`（经度、纬度）、`aa`、`time`、`edittime`、`href`，安全跳过 `icon` 引用；不会执行源站脚本。来源网页按 UTF-8 解码（HTTP 指明其他编码时使用所指编码）。来源结构变化时可能需要调整。当前环境未能对实时源站做端到端验证。
- 浏览器 GPS 坐标通过高德 `convertFrom` 转为高德坐标；来源坐标暂按原值展示，必须先核验其坐标系及若干点位、定位位置和距离，确认转换方案后才能依赖地图结果。
- 需要真实高德 Key、网络及 HTTPS 环境完成地图、定位授权/拒绝、移动端与来源失败等端到端验收。公开使用或再分发前需确认进京365的数据使用条款和授权。

## Sites 托管

仓库包含 Sites 构建配置。历史站点及其当前运行版本、访问权限和配置未在本次修改中验证；本地修改不会自动更新线上站点。

`worker.js` 是 Sites / Cloudflare Workers 后端，`build.mjs` 将页面资源与解析器打包到 Worker，运行 `npm run build` 输出 `dist/server/index.js`。`.openai/hosting.json` 保留现有站点标识。`server.js` 用于本地 Node 开发。两种后端均使用进程或 isolate 内存缓存，重启或回收后缓存会丢失；限频和并发合并仅在单实例内生效。

在 Sites 环境变量中配置 `AMAP_KEY` 与 secret `AMAP_SECURITY_CODE`，重新部署后生效。设置服务端安全密钥后页面自动使用代理，不再要求用户输入。安全密钥不得写入源码。

## 道路颜色

红色表示根据名称或附近高德道路推测为主路、高速或高架；黄褐色包括辅路、地面、匝道及待确认。聚合点显示默认样式，放大后可查看单点颜色。详情显示判断依据；分类不能保证准确，尤其是并行道路、立交和坐标偏移处。当前范围内部分待确认点会向高德发送探头坐标查询附近道路，每次打开页面最多请求 100 次，失败或未查询的点保持待确认。需要高德地理编码权限及额度。
